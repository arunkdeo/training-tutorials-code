#Micro Service API Gateway URLS
* **Subtraction** ->
  - URL->  http://localhost:9090/calservice/subtraction/subtract
  - Input ->
    ```
    {
  "minuend":50.75,
  "subtrahend": -6.25
  }
```
* **Addition** ->
 - URL -> http://localhost:9090/calservice/addition/sum
 - Input ->
```
{
  "augend":50.75,
  "addend": -6.25
}
```
